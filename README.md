## 🌍 What is Lacspace

**Lacspace is a global, country-neutral technology company** building a connected ecosystem of **AI-powered software**. Founded in **2021**, we design, build and run products across healthcare, business operations, education, hospitality, commerce, logistics and fintech — for **100+ clients worldwide**, with teams and offices across **Asia**.

We believe great software should be **judged on craft and impact — not on the postcode of the team.** One flexible, no-code engine powers many products, so each one is configured to a business rather than rebuilt from scratch.

> _Software that thinks · machines that act · systems that reach beyond Earth._

## 🎨 Brand

The Lacspace mark is a neural head-profile — a network that _thinks_. Full brand guidelines, colours and downloads live at **[lacspace.com/brand](https://lacspace.com/brand)**, and the mark ships as code in [`@lacspace/brand`](https://www.npmjs.com/package/@lacspace/brand).

| Colour | Role | HEX |
| :-- | :-- | :-- |
| Lacspace Orange | Primary | `#F97316` |
| Lacspace Violet | Accent | `#7C3AED` |
| Lacspace Blue | Dark accent | `#3B82F6` |
| Lacspace Cyan | Mark | `#0BB9D9` |
| Ink | Surface (dark) | `#0A101C` |
| Off-White | Surface (light) | `#FAFAFA` |
